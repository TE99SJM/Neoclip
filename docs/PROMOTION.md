# NeoClip launch and promotion kit

Use these descriptions to promote NeoClip without promising features or support that do not yet exist. Verify the install workflow before sharing a link widely. Use your own or permitted video footage for demos.

## One-line description

**NeoClip is a self-hosted, browser-based video clipper for marking, queuing, and exporting clips from videos on your own server.**

## Short description

Clip videos from a browser without uploading your footage to a third-party editing service. NeoClip uses FastAPI and FFmpeg to mark in/out points, organize clip queues, and export individual MP4 clips or highlight reels. The current source is available on GitHub for review and local evaluation.

## Community post

**Showcase: NeoClip — a self-hosted video clipping web UI**

I wanted a straightforward way to find useful moments in footage stored on my own server. NeoClip lets me browse files, mark in/out points, build clip queues, and export individual clips or a highlight reel.

It is built with Python, FastAPI, and FFmpeg. The current repository is an early code snapshot rather than a polished one-click installer, and I am working on documentation, packaging, and hardening. It is designed for trusted local use, not for direct public-internet exposure.

I'd especially appreciate feedback on the clipping workflow, browser controls, and what would make the tool more useful.

Project: https://github.com/TE99SJM/Neoclip
