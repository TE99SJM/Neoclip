## Suggested images

Save screenshots in `docs/assets/` with these names:

- `player.png` — the player with playback controls
- `clip-queue.png` — in/out markers and queued clips
- `render.png` — export options or render status

Recommended: capture clear 16:9 screenshots at 1600×900 or higher. Crop private media paths, account information, filenames, and other sensitive details. Use media you own or have permission to show.

Once the files are present, add this to the README:

```md
![NeoClip player](docs/assets/player.png)
![NeoClip clip queue](docs/assets/clip-queue.png)
![NeoClip rendering](docs/assets/render.png)
```

## Short video plan

Aim for a 30–60 second demonstration:

1. Open NeoClip and select a video.
2. Use playback controls to find a moment.
3. Mark in/out and add a named clip.
4. Add a second clip to the queue.
5. Render individual clips or a highlight reel.
6. Show the exported video.

Upload the video to a service you control, or use a GitHub release/discussion attachment, then add a **Watch the demo** link near the top of the README. Do not link to a video until it exists.

**Note:** Screenshots and a demo do not imply that the app is safe to expose on the public internet; keep test instances private.
